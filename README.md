# 信号检测论 · 网球

把**信号检测论（Signal Detection Theory, SDT）**做成一个第一视角网球小游戏的项目。

你站在底线后接球。来球可能落在界内，也可能出界，甚至对面根本没发球——而你必须在**球落地之前**决定挥不挥拍。一轮打 12 球，结束后把你的判断拆成 H / M / FA / CR 四个格子，算出 d′、β、c、A′。

这不只是"打得准不准"的游戏。SDT 关心的是两个**互相独立**的问题：你的感觉有多灵敏（d′），以及你把标准定在哪里（c）。网球恰好把这两件事分得很干净——你可以是个好球员但标准偏保守（不该挥的也放掉），也可以是个差球员但标准冒进（不该挥的也挥）。

## 🎾 在线游玩

纯静态页面，无需安装、无需登录，手机浏览器也能玩（点屏幕代替按空格）。

## 三个页面

| 文件 | 作用 |
|---|---|
| **`index.html`** | 主游戏。打 12 球，出结果页。**先玩这个。** |
| **`end-details.html`** | 《结束页面详解》。结果页上每一个数字是怎么算出来的，逐项复算，不是估算。 |
| **`concept-lab.html`** | 概念实验室。六个可交互板块，拖滑块把 SDT 的每个参数拧一遍。 |

三个页面互相有链接。游戏结果页有个「**进入概念实验室 →**」按钮，会把**你这一轮的 H/M/FA/CR 和 12 个球的落点**通过 URL hash 带进实验室——所以①的分布图底部会画上你实际遇到的球，②的 ROC 上会标出你自己的测点。实验室也能单独打开，成绩可以手输。

## 玩法

1. 选难度：**简单 / 普通 / 困难**
2. 按 **空格** 或**点击屏幕**挥拍；不按就是不挥
3. **一轮 12 球**：6 个界内球（信号）+ 4 个界外球 + 2 个空发球（后两者都算噪音试次）
4. 落地后再挥就来不及了——反应窗口在球落地瞬间关闭

靠近底线的球本来就难判。这不是你手慢，是球的落点余量（到线的距离）小于你的知觉噪声。

## 核心功能：游戏里怎么体现 d′ 和 β

### 一套模型贯穿全部

横轴是**落点余量**（米），以底线为 0，正 = 界内：

```
知觉噪声       σ = 0.30 m（固定）
界外球分布     ~ N(−Δ/2, σ)
界内球分布     ~ N(+Δ/2, σ)        Δ = d′ · σ
判定标准       x_c = c · σ  （米）
```

代入即得 `P(H) = Φ(d′/2 − c)`、`P(FA) = Φ(−c − d′/2)`，于是 `z(H) − z(FA) = d′`、`c = x_c/σ`、`β = exp(d′·c)`——三个式子和结果页、详解、实验室完全自洽。

**这样 c 就有了物理读法**，这是本项目最想讲清楚的一点：

- `c = 0` → 球看起来**刚好压线**你才挥
- `c = +0.5` → 球得看上去**界内 15 cm** 你才挥（保守）
- `c = −0.5` → 球看上去**出界 15 cm** 你也挥（冒进）

### 结果页的六个读数

| 读数 | 含义 | 一句话 |
|---|---|---|
| `P(H)` / `P(FA)` | 击中率 / 虚报率 | 原始比例 |
| `d′` | **辨别力**，与偏向无关 | 两个分布分得有多开 |
| `c` | **判定标准** | 正 = 保守，负 = 冒进 |
| `β` | 似然比刻度 | `= exp(d′·c)`，**与 d′ 纠缠，跨难度不能比** |
| `A′` | 非参数 ROC 面积 | 不假设正态时的替代品 |
| `AUC` | `= Φ(d′/√2)` | 等方差假设下的 ROC 面积 |

### 准确率陷阱

游戏和详解都反复强调：**准确率是个会骗人的数字。**

实验室⑥里有两行可以直接改：

| | H | M | FA | CR | 准确率 | d′ | c |
|---|---|---|---|---|---|---|---|
| 谨慎型 | 4 | 2 | 1 | 5 | **75%** | 1.398 | **+0.268** |
| 宽松型 | 5 | 1 | 2 | 4 | **75%** | 1.398 | **−0.268** |

准确率**完全一样**、d′ **完全一样**，但两个人的处境完全相反：谨慎型连续漏掉该打的球，宽松型连续挥空。准确率看不见这个差别，SDT 能。

### 三档难度

同一名模拟观察者（知觉噪声 σ = 1.0 m）下实测的总体 d′：

| 难度 | d′ |
|---|---|
| 简单 | ≈ 2.4 |
| 普通 | ≈ 1.8 |
| 困难 | ≈ 1.3 |

## 概念实验室：六个板块

| | 板块 | 拖什么滑块 |
|---|---|---|
| ① | **两个分布** | d′、c；切换"固定噪声改难度 / 固定难度改能力"；叠加你这一轮的 12 个球 |
| ② | **ROC 曲线** | 复用①的 d′/c；叠加你自己的测点；可切 z 变换与不等方差 σ(SN) |
| ③ | **标准与奖惩** | 先验 P(S) 与 2×2 收益矩阵，看最优标准 β_opt 被推到哪里 |
| ④ | **比赛耐力模拟** | 一场三盘 12 个时段，疲劳致 d′ 衰减 + 漏报致标准漂移（带种子，可复现） |
| ⑤ | **人 vs 鹰眼** | 人眼与电子司线的 d′ 对照，以及"为什么两边不可直接比" |
| ⑥ | **速查 · 我的成绩** | 你的成绩卡 + 准确率陷阱 + 公式卡 + 常见坑 |

③ 里有个诚实的提示：网球里漏报和虚报都直接丢分，**纯比分意义上收益矩阵是对称的**。真正把最优标准推离中性的，是 P(S)（对手来球界内比例）和体能、局面这类**隐性代价**——所以四个预设改的都是隐性代价的等价换算，不是字面比分。

⑤ 的鹰眼数据已核对：厂商宣传精度 2.6 mm，自述**平均误差 3.6 mm**（约球径 67 mm 的 5%）；2021 澳网是第一个全面用 Hawk-Eye Live 取代司线的大满贯。但关键是——**机器的任务比你的简单**：球已经落地、十台摄像机、没有时间压力。你是在球落地之前预判，还带着视觉噪声和节奏条。所以两边的 d′ 不可直接比较，机器不是"同任务下更强的你"。

## 技术栈

- **纯 HTML + CSS + 原生 JavaScript**，零依赖、零构建步骤
- 每个页面是**一个独立的单文件**，双击即开（`file://` 下也能跑）
- 图表用**内联 SVG** 而非 canvas：可悬停、可加无障碍标签、缩放不糊，且每张图都配表格视图
- 数学函数（`erf` / `Φ` / `zInv` 的 Acklam 算法）与游戏 `computeStats()` 共用同一套实现，保证三个页面数值自洽
- 耐力模拟用带种子的 `mulberry32`，结果可复现

## 已知边界

- **单轮 d′ 封顶在 ±2.93。** 12 球设计下 nS = nN = 6，加上零格的 0.5 对数线性校正（Hautus 1995），z 被夹在 ±1.4652。打出 2.93 的意思是"这一轮我没给出可估的差别"，不是你刚好那么强。想估准 d′ 得多打几轮。
- **β 不能跨难度比。** `β = exp(d′·c)`，d′ 一变 β 就跟着变。要比偏向，比 `c`。
- **耐力模拟是教学示意模型**，含抽样噪声，参数不是实测数据。
